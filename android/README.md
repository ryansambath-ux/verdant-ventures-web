# Verdant Ventures Android app

This is a native Android WebView app that loads the live Verdant Ventures site. Its order forms need internet access.

GitHub Actions builds a debug-signed APK on pushes to the Android project and publishes it at `downloads/verdant-ventures-debug.apk`. This is a test APK, not a Play Store release. The debug signing key is regenerated by the runner. For future updates to an installed app, set up a persistent release signing key and increase versionCode. Receipts generated as browser blob downloads may require opening the website in Chrome; keep the order ID if the download fails.
